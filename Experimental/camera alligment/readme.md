This code is for giving directions to allow camera to stay at the center between two objects i used blue hsv here , the code works by creating a mask and getting contours aka outlines of shapes in mask , removes small ones to avoid noise,merges areas close together together to avoid an object being split into 2,then it gets the center of the shapes using the moment concept that meet requirements which are being in the hsv range and not being small and waits for click to selected the shapes you want to work with which are marked by yellow circles, checks that the clicks are in shapes that meet requirements and circles change to green, checks if one rod is visible and if only one is visible if compares its center with the frame center nd determines whether to move left or right , if none are visible it gives the last known direction , if both are visible it calculates the center position and allows a 30 pixel offset for the camera to be centered all of this is in a loop so you select shapes only once in the beginning
